Potenciométer (HMI_POT) STM32 PC0
• Bal láb (GND): 14. oszlop, c sor → Kék (-) GND sín
• Középső láb (Wiper): 15. oszlop, c sor → STM32 PC0 (ADC1_IN10)
• Jobb láb (+3.3V): 16. oszlop, c sor → Piros (+) 3.3V sín

⚙️ Feszültségosztó Elv

GND 0% elforgatás → 0V
WIPER Mozgó érintkező → PC0
Kimenet: 0V .. 3.3V (analóg)
+3.3V 100% elforgatás → 3.3V
💡 12 bites felbontás: Code = (V_IN / 3.3V) × 4095, azaz 1 LSB ≈ 0.805 mV.
