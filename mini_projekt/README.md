# Félév Végi Mini Projekt
**Mikroprocesszoros Rendszerek Laboratórium**

---

## 🎯 A Projekt Célja
A félév során megismert perifériák és funkciók közül **legalább 3-4 modul integrálása** egy önállóan működő beágyazott rendszerbe.

---

## 📋 Választható Példatémák
1. **AD + Kijelző + PWM**:
   - Analóg bemenet (potenciométer vagy analóg fény/hőmérséklet szenzor ADC-vel).
   - Mért értékek és állapotok megjelenítése LCD / OLED kijelzőn.
   - PWM beavatkozó vezérlése (LED fényerő vagy DC ventilátor fordulatszám).

2. **RTC + Szenzor + Kijelzés**:
   - Valós idejű óra (RTC) kezelése.
   - Környezeti digitális szenzor (I2C/SPI hőmérséklet/páratartalom) periodikus kiolvasása.
   - Időbélyeges adatok megjelenítése kijelzőn vagy soros porti naplózása.

3. **Pong Játék**:
   - Kijelző (OLED / LCD grafikus megjelenítés).
   - Analóg potméteres ütőirányítás (ADC).
   - Időzített labdamozgás (Timer megszakítás).
   - Hang- vagy LED visszajelzés gól esetén.

---

## 🚀 Teendők
1. Hozd létre a saját CubeIDE projektedet ebben a mappában a választott mini projekthez!
2. Konfiguráld az `.ioc` fájlban a szükséges 3-4 perifériát.
3. Írd meg a szoftvert tiszta, modularizált C nyelven.
4. Készíts egy rövid működési leírást a projekt mappájában.
5. Commitold és pushold a saját GitHub repódba a bemutató előtt!
