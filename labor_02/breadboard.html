📍 Pontos Lyuk-Pozíciók

💡 Egy oszlop a-e (vagy f-j) sorainak 5 lyuka belsőleg össze van kötve — nem kell pontosan ugyanabba a lyukba dugni, elég ugyanabba az oszlopba.
LED 1 (Piros) STM32 PD7 (MSB)
• Anód (+): 6. oszlop, c sor (hosszabb láb)
• Katód (-): 7. oszlop, c sor (lapított oldal)
• 220Ω ellenállás: 7b lyuk → Kék (-) GND sín
LED 2 (Sárga) STM32 PD6 (Bit 2)
• Anód (+): 11. oszlop, c sor
• Katód (-): 12. oszlop, c sor
• 220Ω ellenállás: 12b lyuk → Kék (-) GND sín
LED 3 (Zöld) STM32 PD5 (Bit 1)
• Anód (+): 16. oszlop, c sor
• Katód (-): 17. oszlop, c sor
• 220Ω ellenállás: 17b lyuk → Kék (-) GND sín
LED 4 (Kék) STM32 PD4 (LSB)
• Anód (+): 21. oszlop, c sor
• Katód (-): 22. oszlop, c sor
• 220Ω ellenállás: 22b lyuk → Kék (-) GND sín
Nyomógomb STM32 PE5 (Bemenet)
• Felső láb: 26e lyuk → Piros (+) 3.3V sín
• Alsó láb: 28f lyuk → STM32 PE5 láb

💡 LED Polaritás Szabály

ANÓD (+) Hosszabb láb
Bekötése: STM32 GPIO (PD7..PD4)
KATÓD (-) Rövidebb / lapított oldal
Bekötése: 220Ω ellenállás → GND
